# Unit testing nunjucks templates

This is my investigation into how we can use nunjucks to render our templates for unit testing and how to make assertions on the resulting HTML without having to spin up an express server instance.

By using `nunjucks.configure` we can initialise a nunjucks environment using the same parameters as found in `nunjucksSetup.ts`, however without attatching an express app we need to manually call the `render` and `renderString` functions. To help with this I have created a `renderer` function in `nunjucksSetup.test.ts` that can be called to create a render function which can then be used to render templates. For example:

```
const render = renderer(context)
const view = render('appointment/recordSessionDetails.njk')

view.html()
```

The render function returns a CheerioAPI object that can be called with a selector or used with the `.html()` function to return a string of the HTML generated. The context object passed to the `renderer` function should contain all local variables that the template uses, this could be generated by running the `buildViewModel` function of any presenter. The output of which then needs to be assigned to the `content` field of the context object.

`recordSessionDetails.test.ts` contains an example test that could be written, showing the structure of the context object. The cheerio object can also be called with a selector similar to our integration tests, e.g.
```
view([data-testid="appointment-details"])
  .children('.govuk-summary-list__row')
  .children('.govuk-summary-list__value')
```

Further investigation is needed to find a simpler way of selecting elements for assertion (or if a util package should be written).
