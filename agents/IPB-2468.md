# IPB-2468: Display Target Service Completion Date Fields on Referral Details Page

## Summary

Added two new fields from the referral details BFF response (`targetServiceCompletionDate` and `targetServiceCompletionDateReason`) to the **Referral details** summary card on the referral details page.

Both fields already existed as optional, nullable top-level properties on `ReferralDetailsBffResponseDto` in the imported API types.

---

## Files Changed

### `server/referral/referralDetails/ReferralDetailsViewModel.ts`

- Added `targetServiceCompletionDateLabel: string` and `targetServiceCompletionDateReasonLabel: string` to the `ReferralDetailsCard` interface.

### `assets/content/content.json`

- Added label text for both new fields inside the `referralDetailsCard` object under `/referral-details/:id`:
  - `"targetServiceCompletionDateLabel": "What date does the service need to be completed by?"`
  - `"targetServiceCompletionDateReasonLabel": "Why does it need to be completed by this date?"`

### `server/referral/referralDetails/ReferralDetailsPresenter.ts`

- Imported `britishDateFormat` from `../../utils/dateFormat` alongside the existing `dateFormat` import.
- In `buildReferralDetails()`, destructured `targetServiceCompletionDate` and `targetServiceCompletionDateReason` from `this.referralDetails`.
- Added null-safe date formatting for `targetServiceCompletionDate` using `britishDateFormat` (produces `dd/MM/yyyy`).
- Appended two new `govFrontendSummaryListRow` calls after the existing "Assigned to" row.

### `server/testutils/factories/ReferralDetailsContent.ts`

- Added the two new label properties to the `referralDetailsCard` object in the factory.

### `server/referral/referralDetails/ReferralDetailsPresenter.test.ts`

- Added `targetServiceCompletionDate: '2026-12-25T11:23:00.780Z'` and `targetServiceCompletionDateReason: 'Some reason'` to the `dto` in `beforeEach`.
- Added two new expected rows to `createBaseExpected()` in the referral summary list, with the formatted date `'25/12/2026'` and the reason string.

---

## Design Decisions

- **Row placement**: The two new rows appear after the existing "Assigned to" row in the Referral details card.
- **Date format**: `targetServiceCompletionDate` is displayed in `dd/MM/yyyy` format using the existing `britishDateFormat` utility.
- **Null handling**: If `targetServiceCompletionDate` is null/undefined, the row displays the page's `defaultFieldValue` (`"Not available"`). The same applies to `targetServiceCompletionDateReason` via `nonEmptyStringOrDefault`.
